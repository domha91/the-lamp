# Memorial Fonts

Prototype runs with system fonts so it works immediately.
To add fonts:
- place WOFF2 files in assets/fonts/
- add @font-face in styles.css
- ensure licensing allows redistribution

Goals:
- Scripture: Gothic / Blackletter revival (Textura/Fraktur-derived), legible.
- UI headings: restrained Gothic display.
- Diagnostics: monospace.
